# Models Folder

Place your `.gguf` model file here.

The bot will auto-detect the first `.gguf` file in this folder when you run `.llm start`.

Recommended lightweight models:
- `tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf` (~670MB)
- `phi-2.Q4_K_M.gguf` (~1.6GB)
- `qwen2.5-0.5b-instruct-q4_k_m.gguf` (~400MB)
